# Credits

BeG0nE is built on other people's work. Everyone who helped or inspired it is listed here, however small the
part.

- **[praydog](https://github.com/praydog)**: [REFramework](https://github.com/praydog/REFramework), the mod
  framework and its built-in VR mode for Resident Evil Village. The Village version of BeG0nE is a change to
  REFramework's own two-handed grip code (MIT licence).
- **The Khronos Group**: the [OpenXR](https://github.com/KhronosGroup/OpenXR-SDK) headers and loader that Flickers
  BeG0nE is built against (Apache 2.0 licence). REFramework's plugin header is used for the RE4 fix (MIT licence).
- **[elliotttate](https://github.com/elliotttate)** and **[webhead2oo9](https://github.com/webhead2oo9)**: the OpenXR
  Simulator, which let Flickers BeG0nE be built and tested with no headset.
- **Capcom**: Resident Evil Village and the RE Engine. This is a non-commercial fan project. It needs a
  legitimately owned copy of the game and shares no original game files or assets.

If your work is used here and is not credited, or is credited wrongly, please open an issue. It will be fixed
promptly and without argument. We also honour correction and removal requests from rights holders.
